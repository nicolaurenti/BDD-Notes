# Instrucciones del baúl de Obsidian

- Siempre que se cree, modifique, renombre o elimine un archivo de este baúl, guardar los cambios en Git mediante un commit y hacer push al remoto antes de dar la tarea por terminada. Agrupar en un commit los cambios de una misma tarea.
- El usuario consulta este mismo proyecto desde su tablet y hace pull después de los cambios realizados aquí; mantener el remoto actualizado es parte de completar cada tarea.
- Revisar el diff antes de confirmar. Si el remoto tiene cambios, integrarlos conservando el trabajo local. No usar force push ni descartar cambios para sincronizar.
- Si el commit o el push falla, informar que la sincronización quedó pendiente y el motivo; no afirmar que los cambios están disponibles en la tablet.
